# VITALFLEX Training v1.3 — correctif

Version noir, blanc et or. Réparation du chargement des exercices, de la conservation des séries lors de la navigation et ajout du rafraîchissement du cache applicatif.

## Mettre à jour
1. Dans VITALFLEX Training > Données, exporter une sauvegarde JSON.
2. Dans le dépôt GitHub Pages existant, remplacer les six fichiers à la racine.
3. Faire « Commit changes » avec le titre `VITALFLEX Training - Version 1.3 - Correctif des exercices et des séries`.
4. Sur le Samsung, fermer l'application et la rouvrir. Si besoin, actualiser la page depuis le navigateur.

Les données restent dans la même clé localStorage (`vitalflex-training-v1`). Elles ne sont pas synchronisées entre appareils.
